# 中文说明告警与检查报告修复记录

日期：2026-10-30。范围与完成条件见 [修复方案 v3](../plans/note-freshness-repair-plan.md)，测试点见 [TESTS.md](../TESTS.md)。本记录是本次实现自检与真实阅读器验证，不替代独立角色验收。

## 实际变化

- 前端按来源从全量技能状态显示一个默认折叠的中文说明汇总，分组列出待复核、待整理技能的详情链接；普通诊断保留，卡片及详情自身状态不变。筛选不影响全库数量，同页筛选保留展开状态，详情返回保留列表筛选。
- smoke 在校验前发布带运行身份的 running 报告，在成功或可捕获失败时发布本轮 passed／failed。固定报告文件采用完整写入后替换，运行占用阻止并发覆盖；硬中断留下的 running 只表示未完成。报告不可写时明确失败，不再用旧成功冒充本轮结果。
- 对当前 350 项批准来源中的 21 个待处理项逐项审读：18 条已有说明中 8 条定向补充，10 条保留中文文案，另新增 3 条说明。其余 329 条记录内容保持一致，采纳前再次核对源文件摘要。
- 原定 18 项以外的 strategic-compact、tinystruct-patterns 和 typescript-patterns 随当前来源变化出现。依据用户提供的 350 项现状及“开始实施”，在同一批准 ECC 来源内完成这三项逐项审读；没有接受未经审读的摘要或处理其他来源。

## 保持项和限制

350 份安装技能原文摘要未变，原有无关工作区内容及暂存边界保留。API、哈希判定、网络策略和新流程指南行为未因本次修复改变；历史来源基线未覆盖。来源相对历史基线的差异与当前笔记是否已经复核是两种证据，不用重录基线消除历史变化。

浏览器窗口的现有旧界面需要重新加载网页以读取新前端。服务使用当前静态构建和刷新后的资料，未改变服务或网络配置。实施阶段未自动执行 Git 操作；提交和推送按用户后续明确授权处理，具体提交以仓库记录为准。
