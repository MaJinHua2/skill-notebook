# 收录输入与公开输出

私有主数据位于 `.local/catalog.json`；网页读取 `public/catalog.json`。在工程根目录运行命令。原始批次应放入忽略的 `.local/`，不要放到仓库其他目录。

以下 UUID 是合成示例。实际收录必须使用原生接口得到的真实来源，不能复制示例充当证据；真实值只保留在本地私有文件中。

```json
{
  "sources": [
    {
      "id": "00000000-0000-4000-8000-000000000001",
      "title": "本地私有来源标题",
      "url": "codex://threads/00000000-0000-4000-8000-000000000001"
    }
  ],
  "skills": [
    {
      "invocation": "ecc:codebase-onboarding",
      "chinese_name": "项目代码导览",
      "summary": "理解陌生代码库，梳理架构、入口、数据流和开发约定。",
      "scenarios": ["接手旧项目，先建立整体认识"],
      "categories": ["项目理解与开发文档"],
      "provider": "ECC",
      "sources": [
        {
          "thread_id": "00000000-0000-4000-8000-000000000001",
          "turn_id": "00000000-0000-4000-8000-000000000002"
        }
      ],
      "aliases": [],
      "notes": "侧重入门指南，不代表完整模块设计文档。",
      "verification": "已核对本地技能定义"
    }
  ]
}
```

`verification` 只支持“已核对本地技能定义”或“来自对话介绍”，不证明执行效果。插件归属须与完整调用名一致。

更新按调用名匹配。中文名、概括、notes 和核对状态使用最新准确说明；场景、分类、别名及来源默认去重合并。临时输入字段 `replace_lists: true` 可仅针对该技能完整替换场景、分类和别名，来源仍保留；该控制字段不保存到网页。

私有文件使用 schema 1；公开文件使用 schema 2，只导出调用名、中文名、概括、场景、分类、插件、别名、边界说明和核对状态。公开文件不导出来源表、对话标识、原始标题和精确活动时间。公开文本还会经过敏感形态检查。

如公开导出中断，可修正后运行 `python3 scripts/import_notes.py --export` 重新生成，无需重复读取对话。首次克隆后收录新笔记，会先保留克隆中已有的公开笔记，再建立本机私有资料。
